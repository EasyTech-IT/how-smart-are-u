# How Smart Are U

An original word-search puzzle game project.

## Project direction

The project takes inspiration from the word-finding genre, including the
exploration-focused experience of Word Search Explorer by PlaySimple Games.
The planned core loop is to choose a puzzle, find its listed words in a
letter grid, and complete the puzzle.

This project is independent and is not affiliated with PlaySimple Games. It
will use original code, branding, interface design, text, and puzzle content;
no proprietary game assets or content are included.

## Status

Project setup is in progress. No application framework or runnable game has
been added yet.
